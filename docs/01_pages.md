# 01_pages.md
# 花澄の杜 ARG｜ページ仕様

## 共通

- 各ページのHeader/Footerは共通化
- Header/Footerロゴは `index.html` へリンク
- 研究・内部資料・真相は原則1ページ完結
- 重要ストーリー情報はHTMLテキストで記述し、画像内文字に依存しない
- 画像内の生成文字は、仕様上意図したもの以外をUI情報として使用しない

# 1. index.html

## 目的
普通の介護施設サイトとして信頼感を作り、白石芳江、施設だより、認知症ケア、生活支援制度を自然に提示する。

## body
```html
<body data-page="home">
```

## セクション順

### 1. Hero
- 4枚スライド
- `hero-top-01.jpg`
- `hero-top-02.jpg`
- `hero-top-03.jpg`
- `hero-top-04.jpg`
- キャッチ：
  `その人らしい毎日を、いつまでも。`
- サブコピーは介護施設として自然な一般文。ARG情報を含めない。

### 2. #concept
画像：`top-concept.jpg`

見出し例：
`毎日を、その人らしく。`

内容：
- 一人ひとりの生活歴や希望に寄り添う
- 安心できる生活環境
- 家族とのつながりを大切にする
- ARG研究設定を匂わせない

### 3. #features
2つの特長カード。

#### 介護サポート
画像：`top-feature-care.jpg`
- 日常生活・歩行・移動を支援

#### 安心の見守り・連携
画像：`top-feature-medical.jpg`
- スタッフが高齢者に寄り添う様子
- 過度に「医療研究」へ寄せない

### 4. 食事
画像：`meal.jpg`
- 家庭的な和食
- 「お身体に合わせた出来立てのお料理」程度の一般的説明

### 5. 認知症ケア導線
- `care.html` へ
- 通常時は一般的な認知症ケア紹介
- PHASE0では異常を匂わせない

### 6. 白石芳江紹介
画像：`resident-yoshie.jpg`

表示：
- `白石 芳江さん`
- `103歳`
- `入居19年目。現在もご家族との思い出を鮮明に覚えていらっしゃいます。`

ここでは研究対象であることを示さない。

### 7. 新着情報
必須項目：
- `敬老会を開催しました`
- `news-keiroukai.html` へリンク

### 8. 生活支援制度導線
- `support.html` へ
- 保証人がいない方、生活に不安がある方も相談可能という通常の福祉制度として紹介

### 9. #contact
- 問い合わせCTA
- 実送信フォームは必須ではない。ダミーリンク化する場合は `href="#"` のままにせず、クリック不能表現にしないこと。
- 実装するなら簡易フォームでもよいがARG進行に関係させない。

## PHASE差分
TOP自体に重要異常は追加しない。

# 7. support-selection.html

## 目的
生活支援制度が研究対象者の確保・選別にも使われていたことを明示する。

## body
```html
<body data-page="support-selection">
```

## 表示条件
`unlocked.selection === true`

未解放の直接アクセスはTOPへ。

## セクション

### 1. タイトル
`生活支援制度 利用者選定記録`

### 2. 選定基準
HTMLの表/カードで表示。

- 保証人：なし
- 緊急連絡先：なし
- 家族との定期面会：なし
- 生活支援制度による入居
- 神経組織適合性
- 長期観察可能性
- 研究対象適合度

「社会的に追及されにくい条件」も評価に含まれることが分かる構成。

### 3. 症例カード
画像：
`subjects-cases-cards.jpg`

**画像には文字を焼き込まない。**
2×2の人物写真シートとして使用する。

実装方法：
- 4カードをHTMLで作成
- 同一画像を `background-image` にして `background-size: 200% 200%`
- A/B/C/Dごとに `background-position` を変更して各人物を切り出す
- 文字情報はすべてHTML

表示情報：

#### 被験者A
- 置換率：34％
- 症状：記憶混乱

#### 被験者B
- 置換率：52％
- 症状：発話障害

#### 被験者C
- 置換率：68％
- 症状：自己認識低下

#### 被験者D
- 置換率：81％
- 症状：処置中止

### 4. 白石芳江への還元
- 各症例の成功/失敗が白石芳江の次回処置へ反映
- 彼らは芳江を安全に100％へ到達させるための試験対象だったと明示

### 5. 最終記録
```text
研究目的達成
最終対象：白石 芳江
最終研究報告書作成済
```

ボタン：
`最終研究報告書`

クリック時：
- `unlocked.truth = true`
- `truth.html` へ
- ここでは新たな「サイトが改変されました」演出を必須としない
